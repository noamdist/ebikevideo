# 视频编辑子项目

- [01_儿童电摩长版](01_儿童电摩长版/README.md)：原有剪辑记录、审片图片，以及 v4、v5 版本工程。
- [02_儿童电摩30秒版](02_儿童电摩30秒版/README.md)：30 秒字幕版、定格结尾处理与审片资料。

每个子项目统一使用：

1. `01_原始素材/`：原视频、音频、图片素材。
2. `02_编辑工程/`：编辑脚本、剪辑决策、字幕、工作文件和审片记录。
3. `03_导出成片/`：最终导出及交付文件。
4. `04_脚本与分镜/`：文案、镜头表和分镜。

人物参考统一从 `../人物角色/` 取用。新增视频时，建立新的编号子项目并沿用上述结构。
