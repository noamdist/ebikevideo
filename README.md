# EBIKE 视频制作

电动自行车视频制作项目，集中管理人物角色参考素材与视频编辑子项目。

- [项目目录说明](项目目录说明.md)
- [人物角色](人物角色/README.md)：Zara 基准图、提示词和角色参考包。
- [视频编辑子项目](视频编辑子项目/README.md)：儿童电摩长版与 30 秒版的编辑工程、字幕和审片资料。
- `sources/`：只读同步参考文件。
- `skills/`：可复用的角色参考技能。

`output/imagegen`、`outputs/video_review` 及工程内的 `30s` 为旧路径兼容链接。现有编辑脚本从项目根目录运行；所引用的原视频及导出视频目前位于本机「下载」目录，未包含在此仓库中。

本地视频工具环境 `.video-tools/` 不纳入版本管理。新素材和成片请放入相应子项目的预留目录。
