# Character Reference Sheet

用于视频的角色身份参考包。基准图的一致性、单图清晰度和后续镜头可用性优先于总览表的装饰效果。

## 资源与工具

- 读取 `artifact-template.json`，按本技能目录解析资源路径。保留 `assets/reference.png` 与 `assets/preview.png`，不覆盖它们。
- 调用可用的 `imagegen` 技能及内置图像生成工具；图像编辑、身份延续、细节增强和参考表合成都使用该工具。先查看本地参考图片，再调用编辑。
- 生成前阅读 [提示词模板](references/prompt-templates.md)。建立角色档案时阅读 [档案模板](references/character-dossier.md)。仅在用户要求继续 Zara 时阅读 [Zara 示例](references/zara-example.md)。
- 工具不可用时，说明限制，保留档案与提示词；不静默更换模型或改用需要 API 密钥的路径。

## 选择角色与确定设定

1. 按“本次明确指令 → 已确认角色档案与身份参考图 → 模板默认值”取值。重新粘贴的示例文字不自动覆盖已确认年龄等信息；确有矛盾且无法判断时只询问冲突字段。
2. **新角色**：用户描述决定身份。内置 Zara 图只提供白底、照明、排版和模块层级的参考，不能把她的面容或姓名带入新角色的基准照。新角色基准照默认只使用其文字与用户指定的身份参考。
3. **延续角色**：用户指定的照片、既有基准图或已确认角色参考表是身份来源。继续 Zara 且未提供替代身份图时，使用内置原始 Zara 图。
4. 记录固定特征：年龄、脸型、五官结构、眼睛颜色、肤色、发际线、发长、发型、身体比例，以及用户提供或参考图可辨认的个人标记。国籍仅按用户信息记录，不从面容推断。
5. 记录当前服装版本：领口、版型、材质、颜色、接缝、牛仔裤破洞位置、鞋型、腕表与包的佩戴侧、耳环款式、包的背法。佩戴侧按角色自身左右记录。模糊次要细节采用合理设定并记录；不编造精确身高、尺寸或不可见标记。
6. 姿势、表情、角度可变；身份固定。用户换装时新增服装版本，保持同一身份，并建立该服装版本的全身基准图。无需为常规步骤逐项索取确认。

## 默认执行流程

### 1. 建立正面肖像基准

生成单人正面头肩肖像：中性表情、直视镜头、完整头顶和下巴、清晰发际线、自然皮肤纹理、柔和均匀光线、纯白背景，无文字或标签。

已有合格正面肖像可复用。已有密集参考表则用其中清晰正面脸作为身份来源，生成独立基准肖像；不要把低分辨率裁切或仅放大处理称为新的高清细节。

检查面容与来源一致、年龄符合设定、眼睛和发型正确、无明显失真，检查通过后将它记为该版本的肖像基准。用户要求先预览时在此交付；否则继续。

### 2. 建立全身基准

引用肖像基准，生成正面中性站姿，全身从头到鞋完整入画，身体比例自然，双手可辨，当前服装与配饰明确，白底和照明与肖像一致。已存在合格同款服装全身图时可复用。

先核对面容，再核对体型、衣服、配饰和肢体；通过后记录为全身基准。不要用失败图建立后续身份来源。

### 3. 生成独立参考图片

默认完整交付下列模块；用户要求子集时按所需模块执行。每张视频输入图独立生成、无文字、无面板边框，以便直接用于视频镜头。

| 模块 | 默认内容 |
| --- | --- |
| 全身转圈 | 正面、约 45° 的 3/4、约 90° 的侧面、约 180° 的背面 |
| 面部身份 | 正面、3/4、侧面轮廓 |
| 表情 | 中性、快乐、愤怒、悲伤、惊讶、担忧、自信、坚定 |
| 姿势 | 中性站立、行走、坐姿、放松、双臂交叉、紧张、准备行动 |
| 穿搭细节 | 领口、针织/实际面料纹理、接缝与肩部、裤装细节、鞋履、腕表、耳环、包、发型 |
| 颜色材质 | 对应实际肤色、头发、衣服、裤装、鞋、包和金属配件的色块及小型特写 |

- 全身和姿势图引用肖像与全身基准；面部和表情图引用肖像基准，需要发型/衣领约束时增加全身基准。细节图引用相应基准或合格物件图。
- 每个分支都回到固定基准。不能只引用上一个衍生结果，逐张链式重绘身份。
- 正面肖像可复用为面部正面与中性表情；全身基准可复用为全身正面与中性站姿。材料特写可复用已合格细节图。索引中注明复用关系，避免重复生成。
- 转圈图保持同一人物尺度、镜头高度、自然透视、照明和中性站姿。真正侧面和背面不回头看镜头；镜头运动不替代人物朝向。
- 表情改变肌肉而不改变五官结构。悲伤偏嘴角与眼神下垂，担忧偏眉心收紧；自信偏放松稳定，坚定偏专注收紧，保持自然。
- 手、包、头发尽量不遮挡需要识别的结构。衣物、材质、配饰特写必须对应角色实际穿戴物品，不能用通用商品照片替代。

### 4. 汇总参考表

独立图片检查通过后，用合格图片作为图像参考生成白底大型竖版总览。必要时先形成分区参考图，再汇总，适应工具输入限制。不要先生成整表再裁成视频输入图。

沿用内置表的层级：四视角 → 三个面部视角 → 八种表情 → 七种姿势 → 穿搭细节 → 颜色和材质。四视角与面部占主要空间，统一间距，避免拥挤或截断人物。

总览允许指定姓名、准确年龄和面板标签，标签默认沿用参考表英文，也支持中文或无标签；只出现允许的文本。按实际角色调整服装模块，不套用 Zara 的衣物。

合成可能引入漂移，需再次对照基准和单图。原始合格单图始终作为视频输入的主要资源。若一张表无法保持可读性，交付分区表并说明，不隐藏缺失项目或用低清总览替代单图。

## 清晰度与质量处理

- 以独立图片提供真实可用细节。请求工具可提供的最高合适原生分辨率，在提示中表达尺寸目标，但不编造工具不存在的尺寸参数。
- 检查保存文件的真实像素宽高并记录。不能把“4K”“超清”提示、显示尺寸或插值放大当成原生清晰度。工具未达到目标时如实报告实际尺寸，不反复尝试同一句分辨率要求。
- 自然皮肤、细发丝、眼睛边缘、针织纹路、牛仔接缝和金属细节清楚，避免过度锐化、光晕、磨皮和塑料感。增强模式优先固定身份，不能为锐利而重塑五官。
- 对照固定基准检查身份、发型、肤色、比例、服装与配饰、角度、裁切、手部肢体，以及总览文本和模块完整性。
- 明显问题优先只修正受影响资产，再更新对应总览。每个失败项通常最多两次针对性重试；仍不合格则记录问题并交付可用部分，不声称全部完成或绝对一致。用户授权继续时再处理。

## 保存与交付

在任务工作区保存 `output/characters/{character-slug}/{version}/`，不写入只读 sources 或技能自带参考资源。保留原始文件，新版本使用新目录。

建议内容：`identity/` 肖像和全身基准、`turnaround/`、`faces/`、`expressions/`、`poses/`、`details/`、`sheets/`、`prompts/`，以及 `character-dossier.md` 与 `asset-index.md`。仅创建实际需要的目录。

- 保存实际调用提示词、参考图角色与来源路径、服装版本、每张资产真实尺寸、合格状态及修正后版本；不把请求尺寸写成实际尺寸。
- 输出基准图和总览预览、完整参考包目录或打包文件链接，简述质量限制。存在未完成模块时明确指出。
- 给出镜头选图说明：对白/近景使用面部基准或匹配角度；全身/动作使用全身基准或对应姿势；侧后方镜头使用对应侧背视角。按视频工具允许数量选择身份与服装参考。
- 这个技能建立参考资料，不自动生成、上传或发布视频，也不创建定时任务。
