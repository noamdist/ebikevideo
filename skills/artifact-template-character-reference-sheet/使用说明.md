# 视频角色参考表 Skill 使用说明

在聊天中输入 `$artifact-template-character-reference-sheet`，再描述角色和任务，即可调用已安装的技能。也可以明确要求“按照项目中的这个 SKILL.md 执行”，并引用同目录的 [SKILL.md](SKILL.md)。

官方关于 `$` 前缀调用技能的说明：[OpenAI 官方说明](https://developers.openai.com/blog/eval-skills)。

## 推荐流程

第一次使用时，先建立正面肖像和正面全身基准照，查看面容与穿搭是否满意；确认后，再展开完整参考包。后续视角、表情和姿势都引用同一组基准图。

独立单图用于视频生成，竖版总览表用于浏览完整设定。技能会记录图片实际像素尺寸，保存角色档案和实际生成提示词。

## 示例一：先生成 Zara 基准照

复制以下内容发送到聊天：

```text
使用 $artifact-template-character-reference-sheet，沿用已有 Zara 的面容和穿搭，年龄为 20 岁。

先生成清晰的正面肖像和正面全身基准照，采用白色背景、自然工作室光照，无文字。完成这两张后先给我查看。
```

## 示例二：基准照满意后，生成完整参考包

```text
使用 $artifact-template-character-reference-sheet，以刚确认的 Zara 肖像和全身基准照为固定参考，生成完整的视频角色参考包。

包含四个全身视角、三个面部视角、八种表情、七种姿势、服装配饰与材质细节。先生成独立清晰单图，再汇总竖版参考表，保存角色档案、实际图片尺寸和生成提示词，输出到当前项目。
```

## 示例三：创建新角色

```text
使用 $artifact-template-character-reference-sheet，创建新角色 Maya：25 岁美国成年女性，短棕色卷发、棕色眼睛、运动体型，穿白色 T 恤、深蓝牛仔裤和白色运动鞋。

用于连续视频场景。先生成正面肖像与全身基准照，完成后给我查看，再继续制作其他参考图。
```

## 使用已有角色照片

附上角色照片，并注明“以这张照片作为身份参考”。如果提供多张图片，说明哪些固定面容、哪些参考穿搭或排版。

后续换装、补表情或增加视角时，继续指定已确认的基准图。新角色不会默认继承 Zara 的面容；内置 Zara 图仅可用作版式参考。

## 输出位置与视频选图

参考包默认保存在任务工作区的 `output/characters/{角色名称}/{版本}/`，完成后会提供实际文件链接。

- 对白、口播、近景：使用正面肖像或匹配角度的面部单图。
- 全身、行走、坐姿：使用当前穿搭全身基准与匹配姿势单图。
- 侧面、背面镜头：使用对应侧背视图，按视频工具允许的参考数量补充肖像基准。

完整生成包含多次图片生成。只需要部分内容时，可以直接说明“只生成基准照”“只补三个表情”或“只制作四视角”。
