# Zara 示例：沿用既有角色

仅在用户明确要求继续 Zara 时使用本示例。内置图片对于其他角色只有布局参考作用。

## 已确认设定

- 姓名：Zara。
- 年龄：20 岁、成年。会话最初明确要求 20 岁，优先于示例原文的“20 多岁末”。
- 身份背景：美国女性，来自用户要求，不能将国籍作为固定面容的替代描述。
- 外貌：苗条/运动体型，温暖浅色肤色，椭圆脸，深棕色眼睛，自然眉毛、直鼻、自然粉色嘴唇，长深棕色柔和波浪发，中分。
- 原图呈现：自然皮肤纹理及轻微可见雀斑，不夸张加深；自信且平易近人。
- 服装：黑色圆领针织毛衣、浅蓝色宽松破洞牛仔裤、干净白色运动鞋、简约腕表、小型耳环、黑色肩包。
- 左右细节以图为准：按角色自身左右记录。参考正面人物主要可见左腕表、左肩包；如果某个小面板模糊或不一致，沿用肖像/全身基准中明确的设定，不同时保留冲突版本。
- 两膝破洞的位置、包的形状、毛衣织纹和配饰款式沿用原图，建立独立基准后以基准为准。

## 实际调用示例

用户：“用这个 skill，给 Zara 建立视频用的完整角色参考包。”

1. 查看内置原图，以其中正面面部为身份来源，生成一张无文字正面头肩肖像。
2. 对照原图检查脸型、五官、发型和肤色，以合格肖像作为固定身份基准。
3. 引用肖像与原图中全身穿搭，生成无文字、头到鞋完整的正面全身基准，检查服装与配饰。
4. 各自引用固定基准完成全身视角、面部、表情、姿势和材质；复用中性图，避免重复生成。
5. 生成总览，检查文字、模块和身份，并保存档案、资产索引、实际尺寸及提示词。

用户：“创建 25 岁的 Maya，短卷发、白 T 恤、黑裤，做视频角色参考包。”

不要引用 Zara 的脸生成 Maya 的肖像。先根据 Maya 描述建立新的身份，再沿用相同的参考包模块；Zara 图只在最终布局阶段作为可选版式参考。
